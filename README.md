# HDG Redirector
A simple NodeJS redirector for use when moving to new domains. This was whipped up in like 3 minutes, please don't expect error tolerance.

## Deployment
Clone the repo
```sh
git clone https://github.com/HaloDevGames/redirector
cd redirector
```
Populate the `.env_sample` and rename it to `.env`
Instal dependencies and start
```sh
npm install
npm start
```
